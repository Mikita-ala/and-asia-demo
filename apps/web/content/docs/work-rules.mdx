# Работаем в одном ритме

## Договорённости рядом

Сохраняйте важные договорённости в задачах и делитесь новостями вовремя — так команда быстрее движется вперёд.

## Бережём общее пространство

Пользуйтесь материалами команды бережно: они помогают всем сохранять единый темп и качество работы.

## Улучшаем вместе

Заметили, как сделать понятнее? Поделитесь идеей с командой — знания должны расти вместе с нами.
